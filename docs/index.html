Axiom Works AgentReader

Pay-per-call tools for AI agents. No signup, no API key: call the endpoint, get HTTP 402, pay in USDC on Base with x402, get JSON. Also an MCP server.

MCP (streamable HTTP): https://api.axiomworks.co.uk/mcp
HTTP base:             https://api.axiomworks.co.uk
Docs for LLMs:         https://api.axiomworks.co.uk/llms.txt
OpenAPI:               https://api.axiomworks.co.uk/openapi.json
x402 discovery:        https://api.axiomworks.co.uk/.well-known/x402
A2A card:              https://api.axiomworks.co.uk/.well-known/agent.json
Free samples:          https://api.axiomworks.co.uk/samples  (8/IP/day, or ?preview=1)
