# Australian Company Lookup (ASIC)
Batch lookup of Australian companies (ACN, ABN or name) from the official ASIC Company Dataset on data.gov.au (CC BY 3.0 AU). Returns name, current name, type, class, status, registration and deregistration dates.

Also available as a pay-per-call x402 API for AI agents: `https://api.axiomworks.co.uk/au-company?acn=000000019` ($0.02 USDC) and MCP tool `au_company` at `https://api.axiomworks.co.uk/mcp`.
