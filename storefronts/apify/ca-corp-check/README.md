# Canada Federal Corporation Lookup
Batch lookup of active Canadian federal corporations (Corporations Canada open data, OGL-Canada) by corporation number, Business Number or name.

Also an x402 pay-per-call API for AI agents: `https://api.axiomworks.co.uk/ca-company?number=8660115` ($0.02 USDC) and MCP tool `ca_company` at `https://api.axiomworks.co.uk/mcp`.
