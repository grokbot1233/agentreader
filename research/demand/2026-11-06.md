## Top evidence (with links)

1. **On-chain single-fact APIs still own unique payers.** CDP Bazaar (sampled 2026-11-06): `api.onesource.io/api/chain/erc20-balance` **536 unique payers / 541 calls / $0.003**; block-number 492; live-balance 437; contract 403; erc20-transfers 396; ENS 363. Pattern: **payers ≈ calls** (explorer wallets try each listing once). [CDP discovery API](https://api.cdp.coinbase.com/platform/v2/x402/discovery/resources). We already ship `/chain/*` + `/wallet`/`/tx`/`/ens` — breadth matter, but ARPU is pennies unless listed as many distinct resources.

2. **Repeat volume (calls ≫ payers) is rare and mostly LLM / opinion.** blockrun.ai chat **301 payers / 89,612 calls**; ax1.vc q-verdict **246 / 48,507** at ~$0.02. Inference has COGS → skip. Token “verdict” competitors validate our `/token-check` niche.

3. **Web search / scrape is #2 category by historical Bazaar volume** (~218k calls / 24k payers in 2026-11-05 full pull) — [research/market-2026-11-05.md](../market-2026-11-05.md). We have `/read`, `/search`, `/read-batch`. Competitors: Exa resale, ScrapeGraphAI via Toll402 at **$0.20**/search ([toll402.dev/v1/find?need=web+scrape+search](https://toll402.dev/v1/find?need=web+scrape+search)).

4. **Company / KYB / enrichment is a real paid bucket** (~46k calls / 7.5k payers historically). Toll402 ranks Brazilayer CNPJ KYB pack at **$0.0575** and Lion company research at **$0.03–0.0345** for “org enrich before people enrich” ([toll402 find KYB](https://toll402.dev/v1/find?need=company+kyb+sanctions+enrichment)). Off-x402: NewcoSignal **£49–149/mo**, Apify Agentic KYB **~$0.05/check**. We already ship `/kyb` $2.50, `/registry-batch` $0.30, UK/AU/CA registries, sanctions.

5. **Email hygiene is sold as a first-class agent tool.** Toll402 first-party **`verify_email` $0.001** (syntax, MX, disposable, free-provider) in [catalog](https://toll402.dev/v1/catalog). MCP Registry lists domain-level email posture (`ai.kaiv/email-check`) and agent inboxes — but **address-level verify is still a gap on AgentReader** (we only expose MX/SPF/DMARC via `/check` for **domains**). Apify Store has multiple email-validation actors (lead-list buyers). GitHub agent builders repeatedly need deliverability gates before outreach/onboarding.

6. **Own funnel reality:** Cloudflare analytics ~6.5k req/36h with **~2k HTTP 402s**, majority uptime/catalog probes that never pay ([research/revenue-2026-11-05.md](../revenue-2026-11-05.md)). Real outside settles: **$0.003**. Highest EV is anything that (a) sits in explorer sweet spot **$0.001–0.005**, (b) attaches to KYB/leads workflows we already sell, or (c) is a distinct Bazaar/x402scan resource.
